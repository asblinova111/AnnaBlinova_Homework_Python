# Автоматизация тестирования с визуализацией в Allure Report

Данный проект содержит автоматизированные тесты для медленного калькулятора и сквозного сценария покупки в интернет-магазине Swag Labs с интеграцией отчетов Allure.

## 📌 Системные требования
Перед запуском тестов убедитесь, что у вас установлены:
* **Python** (версии 3.7 или выше)
* **Allure CLI** (консольная утилита для сборки отчетов)
* Браузеры **Google Chrome** и **Mozilla Firefox** (с установленным драйвером geckodriver)

---

## 🚀 Как запустить тесты для формирования отчета

Для запуска тестов и сбора результатов для Allure выполните команду в терминале:

```bash
pytest --alluredir=allure-results
```

*После выполнения этой команды в корне проекта создастся временная папка `allure-results` с сырыми данными тестов (JSON-файлами).*

---

## 📊 Как просмотреть сформированный отчет

Для просмотра красивого интерактивного HTML-отчета воспользуйтесь одним из двух способов:

### Способ 1. Автоматический запуск локального сервера (Рекомендуемый)
Утилита сама соберет отчет во временную папку и сразу откроет его в вашем браузере по умолчанию:
```bash
allure serve allure-results
```

### Способ 2. Статическая генерация отчета
1. Скомпилируйте JSON-данные в постоянную HTML-папку:
   ```bash
   allure generate allure-results --clean -o allure-report
   ```
2. Откройте сгенерированный отчет в веб-интерфейсе:
   ```bash
   allure open allure-report
   ```

## 🛑 Важное примечание по работе с Git
Директории с результатами (`allure-results`) и готовыми отчетами (`allure-report`) добавлены в исключения, так как они генерируются локально при каждом запуске. Пушить их в удаленный репозиторий GitHub не нужно.
