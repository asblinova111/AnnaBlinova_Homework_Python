БАГ-РЕПОРТ: Некорректная обработка символов табуляции в методе trim()


1. ID дефекта: DEF-001
2. Компонент: string_utils.py (класс StringUtils, метод trim)
3. Заголовок: Метод trim() не удаляет символы табуляции (\t) в начале строки
4. Статус: Открыт / Требует исправления

5. Описание проблемы:
   Метод trim() предназначен для удаления лишних пробелов. Однако текущая реализация 
   удаляет только обычные пробелы (" "), но игнорирует другие виды пробельных символов, 
   такие как табуляция (\t).

6. Шаги для воспроизведения:
   1. Вызвать метод utils.trim("\t\tskypro").
   2. Ожидаемый результат: строка "skypro".
   3. Фактический результат: строка "\t\tskypro" (символы табуляции остались).

7. Доказательства:
   - Тест: test_string_utils.py::TestTrim::test_trim_with_tabs
   - Результат запуска: FAILED (AssertionError)
   - Скриншот/Лог: В терминале видно, что тест упал, так как строка не очистилась.

8. Влияние (Severity):
   - Критичность: Средняя. Метод работает не в полном соответствии со стандартным поведением 
     функции strip() в Python. Если на вход придут данные с табуляцией (например, из CSV или логов), 
     они не будут очищены.

9. Предлагаемое решение (Fix):
   Заменить текущую реализацию с циклом на встроенную функцию Python .strip(), 
   которая корректно обрабатывает все виды пробельных символов.

   Было:
       def trim(self, string: str) -> str:
           whitespace = " "
           while string.startswith(whitespace):
               string = string.removeprefix(whitespace)
           return string

   Стало:
       def trim(self, string: str) -> str:
           return string.strip()

10. Дефект исправлен. Метод заменен на использование .strip(). Тест проходит.
